# LucroJusto

## Etapa 1 — Base

Este projeto representa a base técnica inicial do LucroJusto.

A estrutura foi organizada para preparar a aplicação para futuras etapas, mantendo uma arquitetura simples com HTML, CSS e JavaScript moderno em módulos.

### Objetivo desta etapa
- manter a aplicação funcional e aberta diretamente no navegador;
- organizar a base do projeto em pastas e módulos;
- criar uma identidade visual inicial limpa e profissional;
- preparar a estrutura sem implementar regras de negócio, autenticação ou integrações.

### Regras desta base
- sem Firebase;
- sem autenticação ou login;
- sem regras financeiras;
- sem cálculos de combustível, manutenção, lucro ou custo por km;
- sem funcionalidades que pertencem às próximas etapas.
